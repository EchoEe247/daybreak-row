# Research decision records

**Status: empty; no new product decisions have been approved.**

When research presents a consequential alternative, create a numbered markdown file such as `0001-realism-strategy.md` with:

- **Status:** Proposed / Accepted by owner / Rejected / Superseded.
- **Context:** Current game constraint and evidence.
- **Options:** At least two alternatives, including retaining the current design.
- **Decision proposed:** Rationale and trade-offs.
- **License and mobile implications:** What is known and unknown.
- **Dependencies and reversibility:** Testing criteria, fallback and rollback.
- **Links:** Reputable original sources and related research/roadmap entries.

Claude's recommendations remain **Proposed** until the owner accepts them.
